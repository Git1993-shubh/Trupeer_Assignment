   LLM EVALUATION SYSTEM
   ├─ llm/LLMJudge.js - 180 lines
   │  • evaluate(input) - Main evaluation method

   │  • _parseResponse(text) - Strict JSON parsing

   │

   │  ├─ intent - Does output follow user request?

   │  ├─ information_preservation - Are key facts retained?
   │  └─ meaningful_change - Is output meaningfully different?
   │
   │  Returns JSON:
   │  {
   │    "overall": "PASS",

🎯 QUICK START
═════════════════════════════════════════════════════════════════════════════════

1. CREATE .env FILE:
   
   notepad .env
   
   Add:
   ┌───────────────────────────────────────────────────────────┐
   │ TRUPEER_BASE_URL=https://app.trupeer.ai                   │
   │ TRUPEER_EMAIL=your-email@example.com                      │
   │ TRUPEER_PASSWORD=your-password                            │
   │ TRUPEER_VIDEO_NAME=your-existing-video                    │
   │ LLM_API_KEY=sk-...your-openai-key...                      │
   │ LLM_PROVIDER=openai                                       │
   │ LLM_MODEL=gpt-4                                           │
   └───────────────────────────────────────────────────────────┘

2. RUN PART 2 TESTS:
   
   cd part2
   npm test
   
   Expected: 10 passing tests (green checkmarks)

3. VIEW RESULTS:
   
   npm run report
   
   Opens HTML report in browser

4. RUN PART 3 VALIDATION (OPTIONAL):
   
   cd ../part3
   npm run validate
   
   Expected: 4 prompts validated with confidence scores
